# 깡피소 캐릭터 에셋 확장 (Character Assets Extension)

> **이 확장은 디시인사이드 비공갤 깡갤 대피소에서 배포됐으며, 다른 곳에 해당 확장에 대해 소개할 때는 반드시 출처를 표기해주시길 바랍니다.**
> 
> **깡갤 대피소 주소: https://gall.dcinside.com/mini/tincans**

이 확장은 SillyTavern에서 대화 응답에 맥락에 맞는 이미지를 자동으로 삽입할 수 있게 해주는 기능을 제공합니다.

## 주요 기능

- 캐릭터 전용 이미지 에셋 관리 (업로드 · 끌어다 놓기 · 붙여넣기 · ZIP · URL)
- 대화 맥락에 맞는 이미지 자동 삽입 — 내장 렌더러로 Regex 없이 바로 표시
- 그림 틀 11종 (그대로, 가는 선, 인화 사진, 폴라로이드, 마스킹테이프, 사진 모서리, 우표, 필름, 떠 있는, 글 왼쪽/오른쪽)
- 비슷한 이름 자동 연결 (대소문자·확장자·오타·같은 뜻 단어 `기쁨`→`happy`)
- 별칭: 파일 하나에 여러 이름 붙이기
- 프롬프트 자동 삽입 — `{{img_inprompt}}`를 직접 넣지 않아도 됨
- 에셋 켜기/끄기, 여러 개 선택해서 한 번에 처리
- 갤러리 · 크게 보기 · 채팅창에 태그 넣기
- 채팅 점검 (못 찾은 태그 찾기, 자주 쓰인 / 안 쓰인 키워드)
- 에셋 링크 · 에셋 버전 · 페르소나 에셋 · 그룹 채팅 지원
- 실리 기본 테마와 각종 테마(밝은/어두운/반투명) 호환, 모바일 대응

## 사용 방법

### 1. 이미지 에셋 추가

**에셋** 탭에서 올립니다.

- **이미지**: 여러 장을 한 번에 고를 수 있습니다. 파일명이 키워드로 사용됩니다.
- **ZIP**: 여러 이미지가 담긴 ZIP 파일을 통째로 올립니다.
- **URL**: 이미지 주소로 올립니다.
- 업로드 칸이나 목록에 **끌어다 놓기**, **Ctrl+V 붙여넣기**도 됩니다.

### 2. 채팅에 이미지 표시

**표시** 탭에서 **내장 렌더러**를 켜고, 마음에 드는 그림 틀과 최대 너비를 고릅니다.
Regex 확장으로 쓰시던 분은 **도구** 탭의 *Regex 스타일 받기*에서 같은 틀을 JSON으로 받을 수 있습니다.

### 3. 프롬프트 연결

**프롬프트** 탭에서 **프롬프트 자동 삽입**을 켜면 끝입니다.
직접 넣고 싶다면 캐릭터 설명이나 작가 노트에 아래 매크로를 넣으세요. (둘 중 하나만 쓰세요)

- `{{img_inprompt}}`: 이미지 지침 전체
- `{{img_keywords_grouped}}`: 묶음 키워드 목록 (예: `angry_[1, 2], happy`)
- `{{img_keywords_autogen}}`: 켜진 파일명 목록 (확장자 포함, 자동 갱신)
- `{{img_keywords}}`: 켜진 키워드 목록 (확장자 없이)
- `{{img_count}}`: 켜진 에셋 개수
- `{{charkey}}`: 현재 캐릭터의 실제 에셋 폴더 경로 (링크·버전 반영)
- `{{img_rand::키워드}}`: 키워드로 시작하는 에셋 중 하나의 주소
- `{{img_resolve::이름}}`: 이름에 맞는 에셋 주소

처음 쓰신다면 패널 위쪽 **시작하기** 카드의 버튼 세 개만 누르면 됩니다.

## 이미지 파일 네이밍 규칙

이미지 파일명은 키워드로 직접 사용됩니다. 한 키워드에 여러 이미지를 넣으려면:

- 기본: `키워드.확장자` (예: `joy.png`)
- 변형 1: `키워드_숫자.확장자` 또는 `키워드-숫자.확장자` (예: `joy_1.png`, `joy-2.png`)
- 변형 2: `키워드.설명.확장자` (예: `joy.expressive.png`)

**표시** 탭의 *랜덤 에셋*을 켜면 `joy_1`, `joy_2`처럼 묶인 파일 중 하나를 골라서 보여 줍니다.

## 슬래시 명령어

- `/assets-upload label=키워드 URL`: URL에서 이미지를 받아 지정한 키워드로 올립니다.
- `/refresh-img-keywords`: 에셋 목록과 키워드를 다시 불러옵니다.
- `/assets-gallery`: 에셋 갤러리를 엽니다.
- `/assets-list`: 켜진 파일명 목록을 돌려줍니다.

## 팁

- 마법봉 메뉴(채팅 입력창 왼쪽)의 **에셋 갤러리**에서 이미지를 골라 채팅창에 바로 넣을 수 있습니다.
- AI가 목록에 없는 이름을 자주 쓴다면 **도구 → 채팅 점검**에서 후보를 눌러 별칭으로 연결하세요.
- 토큰을 아끼고 싶다면 당장 안 쓰는 에셋을 눈 아이콘으로 꺼 두세요. 파일은 지워지지 않습니다.
- 포인트 색은 **도구 → 화면**에서 바꿀 수 있습니다.

## 주의사항

- 모든 AI 모델이 태그를 정확히 쓰지는 않습니다. *비슷한 이름 자동 연결*을 켜 두면 대부분 알아서 찾아 줍니다.
- 너무 많은 이미지를 켜 두면 프롬프트 토큰이 늘어납니다.
- 내장 렌더러와 Regex 변환을 동시에 쓰면 이미지가 두 번 보일 수 있습니다. (표시 탭에서 경고가 뜹니다)
