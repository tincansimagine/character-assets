■ 에셋 링크: 이 캐릭터 에셋도 같이 쓰기
  - 링크를 걸면 지금까지는 이 캐릭터 폴더 대신 링크한 캐릭터 폴더만
    썼습니다. [에셋 폴더]에서 '이 캐릭터 에셋도 같이 쓰기'를 켜면
    두 캐릭터 에셋이 함께 나옵니다.
  - 새로 올리는 파일은 이 캐릭터 폴더에 들어갑니다.
  - 이름이 겹치면 이 캐릭터 파일이 먼저 나옵니다.
  - 링크한 캐릭터의 파일은 목록에 링크 표시가 붙고, 여기서 지우거나
    이름을 바꿀 수 없습니다. (이름 정돈도 이 캐릭터 파일만 바꿉니다)
  - 버전 이름 바꾸기·지우기는 목록 대신 버전 폴더를 직접 읽어서,
    같이 쓰는 이 캐릭터 파일을 건드리지 않습니다.

■ 갤러리
  - 좁은 카드에서 썸네일 아래 버튼이 잘리던 문제 수정
    (카드가 좁으면 ⋮ 메뉴에도 있는 버튼부터 숨김)

 v1.3.0 업데이트 (신규)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ UI 전면 개편
  - 패널을 처음부터 다시 만들었습니다. 카드형 레이아웃, 둥근 모서리,
    부드러운 포인트 색으로 정리했고 글자 크기·간격·대비를 전부
    손봤습니다.
  - 탭 순서를 [에셋 / 표시 / 프롬프트 / 도구]로 바꿨습니다.
    마지막으로 연 탭을 기억합니다.
  - 상단 요약 카드: 캐릭터 아바타, 파일·키워드·꺼짐 개수, 링크/버전
    상태를 한눈에 보여 줍니다.
  - 시작하기 체크리스트: 에셋 올리기 → 이미지 표시 → 프롬프트 연결
    3단계를 버튼 하나로 끝낼 수 있습니다. 다 하면 자동으로 사라집니다.
  - 포인트 색 선택: 로즈(기본) / 라벤더 / 피치 / 민트 / 스카이 /
    테마 색. 나머지 색은 쓰고 계신 실리 테마를 그대로 따라갑니다.
  - 밝은 테마·어두운 테마·반투명 테마를 자동으로 감지해서 대비를
    맞춥니다. 색은 전부 테마 색에서 계산하므로 테마를 바꿔도 따라갑니다.
  - 모바일: 좁은 화면에선 2열 카드, 큰 터치 영역, 메뉴는 아래에서
    올라오는 시트로 열립니다. 갤러리는 전체 화면으로 열립니다.
  - 접근성: 키보드만으로 탭·필터·스타일·메뉴를 오갈 수 있고(방향키),
    모든 아이콘 버튼에 이름을 붙였습니다. 모션 줄이기 설정도 따릅니다.

■ 에셋 탭
  - 업로드 영역: 끌어다 놓기, 붙여넣기(Ctrl+V), 이미지/ZIP/URL 버튼.
    붙여넣은 이미지는 이름을 물어본 뒤 올립니다.
  - 업로드 진행 막대: 몇 개 중 몇 개 올렸는지, 실패 개수가 보이고
    중간에 취소할 수 있습니다.
  - 한꺼번에 보내지 않고 3개씩 나눠 올립니다. 통신 오류가 나면 알아서
    두 번까지 다시 시도합니다.
  - ZIP도 같은 이름이 있으면 덮어쓰기 전에 물어봅니다.
    WebP 변환을 켜 두면 ZIP 안의 이미지도 변환해서 올립니다.
  - 필터(전체/켜짐/꺼짐), 정렬(이름순/최근 순/파일 많은 순),
    카드형/목록형 보기 전환
  - 선택 모드: 여러 개 골라서 한 번에 켜기·끄기·삭제
  - 파일마다 [⋮] 메뉴: 크게 보기, 태그 복사, 채팅창에 넣기, 별칭,
    켜기/끄기, 이름 바꾸기, 파일 받기, 삭제
  - 별칭: 파일 하나에 다른 이름을 여러 개 붙일 수 있습니다.
    (예: smile.png 에 "미소, 웃음") AI가 별칭으로 써도 이미지가 나옵니다.
  - 그룹 채팅: 멤버별로 접고 펼 수 있고, 올릴 때 어느 멤버에게 올릴지
    고를 수 있습니다.

■ 표시 탭 (내장 렌더러)
  - 그림 틀 11종: 그대로 / 가는 선(기본) / 인화 사진 / 폴라로이드 /
    마스킹테이프 / 사진 모서리 / 우표 / 필름 / 떠 있는 / 글 왼쪽 /
    글 오른쪽
    · 틀 크기가 최대 너비에 맞춰 같이 커지고 작아집니다.
    · 고르는 칸마다 지금 캐릭터 그림으로 실제 모양을 보여 줍니다.
    · 예전 스타일 설정은 비슷한 틀로 자동으로 옮겨집니다.
  - 최대 너비 조절(120~800px), 아래쪽 미리보기에 바로 반영
  - 눌러서 크게 보기: 채팅 속 이미지를 누르면 원본으로 열립니다.
  - 이미지 아래 이름 표시
  - 비슷한 이름 자동 연결: AI가 이름을 조금 다르게 써도 찾아 줍니다.
    · 대소문자, 공백, _ - . 차이 무시 (Happy Smile → happy_smile)
    · 확장자가 달라도 연결 (joy.png → joy.webp)
    · 묶음 이름 (angry.png → angry_1.png)
    · 같은 뜻 단어 (기쁨 / joy / 嬉しい → happy, 화남 → angry 등)
    · 한두 글자 오타 (suprised → surprised)
  - 못 찾은 태그 처리: 작은 안내 표시 / 숨기기 / 태그 그대로
  - Regex 확장에도 {{img::}} 변환이 켜져 있으면 중복 경고를 띄웁니다.
  - 렌더러를 끄면 채팅의 이미지가 바로 원래 태그로 돌아갑니다.

■ 프롬프트 탭
  - 프롬프트 자동 삽입: {{img_inprompt}}를 직접 넣지 않아도 에셋이
    있는 캐릭터와 대화할 때 이미지 지침이 들어갑니다.
    위치(메인 프롬프트 앞/뒤, 채팅 안 깊이)와 역할을 고를 수 있습니다.
  - 매크로 버튼: 눌러서 커서 위치에 바로 넣기
  - 글자 수 · 토큰 수 표시
  - 저장 안 된 변경 표시, 되돌리기 버튼
  - 저장 안 한 채로 다른 프리셋을 고르면 저장 후 이동 / 버리고 이동을
    물어봅니다.
  - 미리보기: 매크로가 실제로 어떻게 바뀌는지 확인

■ 도구 탭
  - 채팅 점검: 지금 채팅의 태그 수, 못 찾은 이름, 자주 나온 키워드,
    한 번도 안 나온 키워드를 보여 줍니다. 못 찾은 이름 옆의 후보를
    누르면 별칭으로 등록돼서 다음부터 바로 나옵니다.
  - 페르소나 에셋: 페르소나 아바타·개수 표시, 갤러리로 보기
  - 이름 정돈: 바뀔 이름을 미리 보여 주고, 이름이 겹치는 파일은
    건너뜁니다.
  - 남은 설정 정리: 지워진 캐릭터나 없는 파일에 남은 기록을 정리
  - 이 캐릭터 설정 초기화 (파일은 지우지 않음)
  - Regex 스타일 받기: 표시 탭과 같은 11종 틀로 바뀌었습니다.

■ 갤러리 / 크게 보기
  - 갤러리: 검색, 크기(S/M/L), 캐릭터·멤버·페르소나 전환,
    여러 개 선택 후 끄기·삭제, 끌어다 놓아 바로 올리기
  - 썸네일 위 버튼으로 채팅창에 넣기 / 태그 복사 / 켜기·끄기
  - 크게 보기: 해상도·용량·형식 표시, 태그 복사, 채팅창에 넣기,
    파일 받기, 방향키·손가락으로 넘기기, 이미지를 누르면 원본 크기
  - 마법봉 메뉴(채팅 입력창 왼쪽)에 [에셋 갤러리] 추가

■ 매크로 / 명령어
  - {{img_rand::키워드}}, {{img_resolve::이름}} 가 실제로 동작하도록
    고쳤습니다. (최신 실리 매크로 엔진 대응)
  - {{img_keywords}} 가 지운 파일까지 남아 있던 문제를 고쳐, 지금 켜진
    키워드만 나오도록 했습니다.
  - {{img_count}} 가 실제 켜진 에셋 수를 돌려줍니다.
  - /assets-gallery : 에셋 갤러리 열기
  - /assets-list : 켜진 파일명 목록을 돌려줌 (STscript에서 활용)
  - /assets-upload 가 PNG가 아닌 이미지도 확장자를 맞게 저장합니다.

■ 속도 개선
  - 캐릭터를 바꾸거나 새로고침할 때 에셋 목록을 3번 불러오던 것을
    1번으로 줄였습니다. 그룹 채팅은 멤버를 동시에 불러옵니다.
  - 켜기/끄기, 별칭, 정렬, 검색은 서버에 다시 묻지 않고 바로 반영합니다.
  - 스트리밍 중 글자가 들어올 때마다 모든 메시지를 훑던 것을,
    바뀐 메시지만 처리하도록 바꿨습니다.
  - 같은 이름 찾기 결과를 기억해 두어 긴 채팅에서도 가볍습니다.
  - 목록을 한 번에 그리고 이벤트를 한 곳에서 처리해 에셋이 많아도
    버벅이지 않습니다.

■ 버그 수정
  - 메시지를 수정하거나 스와이프하면 이미지 대신 태그가 그대로 보이던
    문제 수정
  - 갤러리·크게 보기·메뉴를 누르면 뒤의 확장 설정 창이 닫히던 문제 수정
  - 메시지를 보낼 때 콘솔에 오류가 나던 문제 수정
  - 이름 정돈 중 업로드가 실패하면 원본이 사라질 수 있던 문제 수정
    (새 이름으로 먼저 올린 뒤 원본을 지웁니다)
  - 대소문자만 바꾸는 이름 변경이 윈도우에서 파일을 지울 수 있던 문제 수정
  - 이름을 바꾸면 꺼짐·별칭 설정이 풀리던 문제 수정
  - 특수문자가 들어간 파일명이 갤러리에서 깨지던 문제 수정
  - 채팅 메시지 전체에 걸려 있던 CSS(contain)를 빼서 일부 테마에서
    메시지 메뉴·장식이 잘리던 문제 수정
  - 확장 팝업용 버튼 스타일이 실리의 다른 팝업까지 바꾸던 문제 수정

■ 버그 수정
  - 실리태번 업데이트 후 이미지/ZIP 업로드가 실패하던 문제 수정
  - 업로드/삭제 실패 시 원인을 알 수 있는 상세 에러 메시지 표시
    (CSRF 만료 시 "페이지 새로고침" 안내 등)
  - 갤러리/원본 미리보기가 모바일에서 화면 밖(페이지 맨 위)에
    떠서 닫을 수 없던 문제 수정 (브라우저 top-layer 방식으로 변경)
  - 삭제 확인 팝업의 버튼 글자가 세로로 쪼개지던 문제 수정
  - 반투명 테마에서 탭-패널 경계선이 비쳐 보이던 문제 수정

■ 신규 기능
  - 태그 복사: 에셋 카드의 태그(🏷) 아이콘으로 {{img::파일명.ext}}
    태그를 바로 클립보드에 복사
  - 개별 이름 변경: 연필(✏) 아이콘으로 에셋 하나씩 파일명 변경
  - WebP 자동 변환: 업로드 시 PNG/JPEG를 WebP로 자동 변환해
    저장 용량 절약 (에셋 탭 체크박스, GIF 제외)
  - 덮어쓰기 확인: 같은 이름의 파일 업로드 시 덮어쓸지 미리 확인
  - 설정 백업/복원: 도구 탭에서 확장 전체 설정(프리셋, 캐릭터별
    설정, 렌더러 옵션)을 JSON으로 내보내고 복원

■ UI 개선
  - 확장 헤더에 버전 배지 표시
  - 에셋 카드 액션 아이콘 터치 영역 확대 및 호버 피드백 개선
  - 노트 탭 스타일: 활성 탭이 아래 패널과 이어져 보이도록 개선
  - 버튼 아이콘-글자 간격, 버튼끼리 간격 전반 확대
  - 테마 호환성 개선: 밝은 테마 등 어떤 테마에서도 카드 경계선과
    안내 문구({{...}} 표기 등)가 항상 보이도록 색상 계산 방식 변경

 1. 에셋 탭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 에셋 폴더 (접어 둔 칸)
  - 에셋 링크: 다른 캐릭터의 에셋 폴더를 같이 씁니다.
    같은 캐릭터의 한국어/영어 카드처럼 중복 저장을 피할 때 좋습니다.
    링크 중에는 올리기·삭제·이름 바꾸기가 잠깁니다.
  - 에셋 버전: 한 캐릭터의 에셋을 하위 폴더로 나눠 두고 바꿔 끼웁니다.
    (예: 기본 / BL / 공통)

■ 올리기
  - [이미지] PNG, WebP, GIF, JPEG 여러 장
  - [ZIP] 압축 파일 통째로
  - [URL] 이미지 주소로
  - 업로드 칸이나 목록에 끌어다 놓기, Ctrl+V 붙여넣기
  - 옵션: WebP로 변환 / 같은 이름이면 덮어쓰기 전에 묻기

■ 목록
  - 같은 키워드(angry_1, angry_2 …)는 카드 하나로 묶입니다.
  - 눈 아이콘: 켜기/끄기 (꺼진 에셋은 AI 프롬프트와 렌더러에서 빠지고
    파일은 그대로 남습니다)
  - [⋮] 메뉴: 크게 보기, 태그 복사, 채팅창에 넣기, 별칭, 이름 바꾸기,
    파일 받기, 삭제
  - 검색은 키워드·파일명·별칭 모두에서 찾습니다.

 2. 표시 탭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AI가 출력한 {{img::파일명.ext}} 태그를 실제 이미지로 바꿉니다.

■ 그림 틀
  그대로 · 가는 선 · 인화 사진 · 폴라로이드 · 마스킹테이프 ·
  사진 모서리 · 우표 · 필름 · 떠 있는 · 글 왼쪽 · 글 오른쪽

■ 랜덤 에셋
  - angry_1, angry_2, angry_3 처럼 묶인 파일이 있으면 AI에게는
    angry 만 알려 주고, 표시할 때 그중 하나를 고릅니다.
  - 파일명 구분자로 _  -  . 모두 지원합니다.

■ 지연 로딩
  - 화면에 보이는 메시지만 처리하고, 이미지는 필요할 때 받습니다.

 3. 프롬프트 탭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 프롬프트 자동 삽입
  켜 두면 이미지 지침이 알아서 들어갑니다. 이미 {{img_inprompt}}를
  직접 넣어 두셨다면 중복되니 둘 중 하나만 쓰세요.

■ 프리셋
  기본 프리셋(범용), 1:1 감정/표정형, 시뮬레이션/장소·아이템형 제공.
  새로 만들기, 이름 변경, 삭제, 내보내기/불러오기(JSON).

■ 지원 매크로
  {{img_inprompt}}          — 이미지 지침 전체
  {{img_keywords_grouped}}  — 묶음 키워드 목록 (예: angry_[1, 2], happy)
  {{img_keywords_autogen}}  — 켜진 파일명 목록 (확장자 포함)
  {{img_keywords}}          — 켜진 키워드 목록 (확장자 없이)
  {{img_count}}             — 켜진 에셋 개수
  {{charkey}}               — 실제 에셋 폴더 경로 (링크·버전 반영)
  {{img_rand::키워드}}      — 키워드로 시작하는 에셋 중 하나의 주소
  {{img_resolve::이름}}     — 이름에 맞는 에셋 주소

 4. 도구 탭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 채팅 점검 — 못 찾은 태그 / 자주 쓰인 키워드 / 안 쓰인 키워드
■ 페르소나 에셋 — 캐릭터 에셋에 없는 이름은 여기서 한 번 더 찾습니다.
■ 백업 & 정리 — 에셋 ZIP 받기, 이름 정돈, 설정 백업/복원,
                남은 설정 정리, 이 캐릭터 설정 초기화
■ 화면 — 포인트 색
■ Regex 스타일 받기 — Regex 확장으로 계속 쓰실 분들을 위한 호환 기능

 5. 그룹 채팅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 그룹 채팅에 들어가면 모든 멤버의 에셋을 함께 불러옵니다.
- 키워드 목록과 렌더러에 모든 멤버의 에셋이 반영됩니다.
- 에셋 탭에서 멤버별로 접고 펼 수 있고, 올릴 때 멤버를 고릅니다.
- 갤러리에서 멤버 전체 / 멤버 하나씩 볼 수 있습니다.

 6. 슬래시 명령어
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

/assets-upload label="키워드" URL   — URL 이미지를 에셋으로 올립니다.
/refresh-img-keywords               — 에셋 목록·키워드를 다시 불러옵니다.
/assets-gallery                     — 에셋 갤러리를 엽니다.
/assets-list                        — 켜진 파일명 목록을 돌려줍니다.

 7. 빠른 시작
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 캐릭터를 선택합니다.
2) [에셋] 탭에서 이미지나 ZIP을 올립니다. (끌어다 놓기·붙여넣기 가능)
3) 시작하기 카드에서 [켜기] → 내장 렌더러가 켜집니다.
4) 시작하기 카드에서 [자동 삽입 켜기] → 이미지 지침이 자동으로
   들어갑니다. (또는 캐릭터 설명·작가 노트에 {{img_inprompt}} 직접 입력)
5) AI가 {{img::파일명.ext}} 로 답하면 이미지가 나옵니다.
